# StepQuest 🛡️👟

**StepQuest** é uma aplicação Android que transforma a tua caminhada diária numa aventura RPG épica. Converte os teus passos reais em progresso no jogo, desbloqueia níveis, melhora o teu herói e explora um mapa medieval repleto de desafios.

## 🚀 Funcionalidades

- **Dashboard de Herói**: Acompanha os teus passos, energia e experiência (XP) em tempo real no `MenuActivity`.
- **Animações Dinâmicas**: Sistema de animação por spritesheets que faz o herói caminhar proporcionalmente ao movimento.
- **Mapa de Aventura**: Navegação por um mapa interativo com diversos níveis e estados (bloqueado/disponível).
- **Sistema de RPG**:
    - **Energia**: Gestão de recursos para atividades.
    - **XP**: Sistema de progressão de nível baseado em metas de passos.
- **Persistência de Dados**: Utilização de **Room Database** para guardar o progresso do utilizador e sessões de exercício.
- **Autenticação**: Fluxos completos de Login e Registo de utilizadores.

## 🛠️ Tecnologias Utilizadas

- **Linguagem**: [Kotlin](https://kotlinlang.org/)
- **Interface**: XML (ConstraintLayout, GridLayout) com Material Design.
- **Base de Dados**: [Room Persistence Library](https://developer.android.com/training/data-storage/room)
- **Ferramenta de Build**: Gradle (Kotlin DSL).
